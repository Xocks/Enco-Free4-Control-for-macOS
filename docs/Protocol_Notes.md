# Free4 协议实施记录

实现来源及固定版本见 THIRD_PARTY_NOTICES。仅接受 PID 068C10，型号元数据保存在 Resources/Free4-reference.json。协议参考以固定版本上游和经校准的公开汇总为准。

- RFCOMM：优先 079A UUID，兼容 1107；SDP 不可用时按上游尝试通道 15。音频连接由系统管理。
- 报文：AA + unsigned LEB128(7 + payload length) + 0000 + command LE16 + sequence + payload length LE16 + payload。最大 payload 65535；按 RFCOMM MTU 分段发送。不能继续使用旧项目单字节总长度。
- 只接受命令与序号对应且 15 秒内的查询响应；推送单独处理。一次只进行一个设置操作。7 秒内必须收到 SET ACK 和随后发出的关联查询中目标值；ACK 后每 700ms 限时重复查询以容纳固件异步更新，不重发设置，否则不显示成功。
- Free4 SET：关闭 bit0；通透 bit2；降噪档位 bit4/5/6/7；自适应 bit11。REPORT：关闭 bit3 或 bit0；通透 bit8 或 bit2；降噪 bit4..7。长按循环为 02 01，不得混入 01 01 的当前模式；智能实时 04 01 同样不能覆盖当前模式。
- 电量：8106 支持 status/count/pairs 和上游 legacy pairs；0204 subtype01 用 count/pairs。低7位电量、高位充电；0、127和>100显示未知。区分未回报组件与显式未知组件。
- 能力：8100 bitmap 与 810D feature table，未知的高级能力不默认开放。订阅 8200 提供的事件；支持0205用批量订阅，否则尝试0201。
- EQ：0122 空 payload（QuickBuds），只有成功枚举后开放自定义编辑；0418 增改删，名称 UTF-8 长度限制不截断字符。保存逐项比较名称、频段、增益；删后重新读取，不能假设 ID 不变。普通版基础音效不是丹拿版音效。
- 手势：8108 为 status/count/4-byte entries；0401 写入，保持设备实际 button group。日常手势与 button06 通话操作分离。未能映射到普通版声明选项的项目不开放。长按循环写 0404 02 01 mask，最少一种。
- 双设备 feature11；已连接设备0112按每条长度解析。未移植未知副作用的额外0413模式控制。
- 固件0105解析设备／版本类型／版本号三元组；0114仅展示设备回报编码，不能由此承诺 macOS 可启用 LHDC。
- 已有听感0115、耳道数据011E只读取，不启动测试、不写方案。协议层长报文已经具备，可在普通版会话校准后继续。
- 0500请求回应当前时间，050C/051C/051D与F2心跳回应参考QuickBuds；不响应未知厂商云命令。

日志只记录方向、命令、序号、长度。关键无个人内容的 PID／固件／电量／模式／能力响应保留最多128字节，其他 payload 脱敏。设备名、MAC、自定义EQ与听感内容不进入导出日志。

## 校准补充

- 普通版元数据规定固件≥118支持预设ID7活力动感，不依赖0122自定义方案列表枚举内置音效。
- 低延迟 feature06 设置ACK之后，第一次010D可能仍返回旧值。使用新序号重复关联查询后得到目标状态，开关与恢复复测通过；不将ACK或推送单独当作操作完成。
- 提示音音量0130/0427已通过修改及恢复；音色方案0121读取通过。内容替换需要0417元信息及deviceType4资源传输，详见Prompt_Tones.md。
- 黄金听感0115严格校验12个左右耳／频率槽；耳道扫描011E严格校验168字节和UID，均已通过实机只读验证。
- IOBluetooth枚举移到后台串行队列，避免SwiftUI构造期间初始化阻塞。连接通知注册有防重入；系统同步回调延后至MainActor任务处理，防止返回token赋值前递归注册。
