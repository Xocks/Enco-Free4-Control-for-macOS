# 实施顺序

本项目采用功能优先级推进：P0 必须完成，P1 重点完善，P2 有边界地尝试，P3 仅研究。只适配 Enco Free4 普通版 PID 068C10。

1. 复用固定版本上游，建立可构建基线、协议来源与功能表。
2. 修复帧、状态与确认机制；完成连接／电量／三种模式及安装。
3. 实机验收 P0；未通过不得称为日常可用版本。
4. 独立验收降噪档位、EQ、手势、双设备及应用便利功能。
5. P2 先读已有状态；失败功能经一次针对性 APK／HCI 校准后暂缓，保留恢复条件。
6. 回归、工作日运行、安装测试、应用／DMG／源码／说明交付。

当前执行证据见 Acceptance.md，逐项状态见 Feature_Status.md。代码实现不是实机验收。
