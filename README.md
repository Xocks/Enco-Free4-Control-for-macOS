# Enco Free4 控制 · Enco Free4 Control for macOS

**中文** | [English](README.en.md)

面向 **OPPO Enco Free4 普通版** 的原生 macOS 菜单栏控制软件。提供中文菜单栏面板和完整设置窗口，基础控制离线运行。仅接受产品 ID `068C10`；丹拿版及其他型号不在适配范围。

> **预览版：核心设置已完成协议回读验证，P0 全场景验收尚未完成。** 睡眠唤醒、单耳／充电、蓝牙关闭／拒绝授权和全天稳定性仍待验证。降噪档位回读成功不等于听感差异已经测量。

## 安装

要求 Apple Silicon Mac、macOS 14 或更高版本。当前界面为中文，英文文档提供同等的安装与功能边界说明。

1. 在 [Releases](https://github.com/Xocks/Enco-Free4-Control-for-macOS/releases) 下载 DMG，将 **Enco Free4 控制.app** 拖入 Applications。
2. 在系统蓝牙中配对并连接 Enco Free4，打开应用并允许蓝牙访问。
3. 选择耳机；应用确认普通版产品 ID 后开放设置。
4. 从菜单栏操作日常噪声模式，进入“完整设置”调整档位、音效和手势。
5. 等待“耳机已回报并确认设置”；超时或拒绝时保留最后回报的状态。

应用采用临时签名，未经过 Developer ID 公证。若 macOS 阻止打开，请按系统“隐私与安全性”中的说明操作。更新时退出旧版本并**完整替换应用包**；绑定和偏好保留在本地容器中。

## 使用说明

- “—”表示没有可用电量；断线或过期数据会标为失效，不推算盒电量。
- 系统蓝牙连接与耳机控制通道分别显示；控制通道不能代替系统音频连接。
- 设置必须获得 ACK，并由后续关联查询返回目标值才显示成功；部分异步设置会限时重复查询。
- 手动断开控制后，本次系统连接期间不会立即自动重连。
- 空间音效与高音质模式存在互斥；实际音频编码由 macOS 与耳机协商。
- 部分实验开关仅在本机和当前固件通过回读验收后开放；新安装可能显示“待验证”。
- 提示音**音量**与提示音**内容／音色**是两个功能；后者尚未实现。

## 构建

安装 Apple Command Line Tools 后，在项目根目录运行：

```sh
Scripts/test-protocol.sh
Scripts/build-app.sh
Scripts/build-dmg.sh 0.1.0
```

输出位于 `dist/`。运行时无需 Android、JADX、Wireshark、账号或网络。无第三方 Swift 包依赖。Command Line Tools 缺少 XCTest 时，独立协议脚本仍可运行；完整 Xcode 环境可另行运行 `swift test`。
