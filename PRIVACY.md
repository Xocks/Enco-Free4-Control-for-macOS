# 隐私说明 · Privacy

## 简体中文

基础控制通过本地蓝牙完成。应用无账号登录、分析统计或自动诊断上传功能。绑定地址、偏好、已确认档位和诊断日志保存在本地应用容器中；用户选择“导出诊断日志”后才写入指定文件。诊断日志省略蓝牙地址、连接设备名称及自定义方案内容。界面按需读取方案名称和耳道数据，但不将其写入诊断导出。

公开版本不附带原始设备验收日志、用户方案、账号信息、私人邮箱、个人历史提交、APK或研究缓存。发布包从干净源码重新构建并排除调试信息；保留必要的许可证及上游来源。

反馈问题时，请只提供软件版本、系统版本、功能及复现步骤。提交日志或截图前，请自行核对并移除姓名、邮箱、蓝牙地址、设备名、方案名、账号、文件路径和其他个人信息。

## English

Core controls use local Bluetooth. The app has no account sign-in, analytics or automatic diagnostic upload. Binding addresses, preferences, confirmed levels and logs stay in the local app container. Diagnostic export writes only to a location selected by the user and omits Bluetooth addresses, connected-device names and personal preset content. Preset names and ear-scan data may be read for display, but are not included in diagnostic exports.

Public source and releases exclude raw device logs, personal presets, accounts, private email, private commit history, APKs and research caches. Release artifacts are rebuilt from a clean source snapshot without debug information. Required licenses and upstream attribution remain included.

Report only the software/system version, affected feature and reproduction steps. Before sharing logs or screenshots, remove names, email addresses, Bluetooth addresses, device/preset names, account data, file paths and any other personal information.
